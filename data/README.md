# Data Sources and Access

This research draws on four primary data sources:

| Source | Purpose |
|---|---|
| IPUMS CPS | Employment and demographic measures |
| Anthropic Economic Index | Occupational AI exposure |
| O*NET | Occupational learning intensity measures |
| U.S. Census Bureau | Occupational classification harmonization |

## Source Access

- [IPUMS CPS](https://cps.ipums.org/cps/)
- [Anthropic Economic Index](https://www.anthropic.com/economic-index)
- [O*NET Database](https://www.onetcenter.org/database.html)
- [U.S. Census Bureau](https://www.census.gov/)

## Data Availability

Restricted individual-level microdata are not distributed
through this repository. Researchers must obtain source
data directly from the respective providers.

## Reproducibility

Detailed extraction specifications, variable definitions,
occupational harmonization procedures and execution
instructions will accompany the analysis code.
